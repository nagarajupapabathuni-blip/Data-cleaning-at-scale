# Data Cleaning at Scale using Python

## Project Overview
This project demonstrates large-scale data cleaning using Python and Pandas on the Netflix Movies and TV Shows dataset.

## Objectives
- Clean raw data
- Handle missing values
- Remove duplicate records
- Perform data preprocessing
- Generate visualizations
- Export cleaned dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## Dataset
Netflix Movies and TV Shows Dataset

## Data Cleaning Tasks Performed
- Removed duplicate values
- Filled missing data
- Converted date columns
- Cleaned column names
- Analyzed dataset structure

## Visualizations
- Movies vs TV Shows
- Top Ratings Analysis
- Country-wise Content Distribution
- Release Year Trend

## Output
Successfully cleaned and transformed raw Netflix dataset into a structured and usable format.

## Files Included
- netflix_titles.csv
- cleaned_netflix_dataset.csv
- Untitled2.ipynb
